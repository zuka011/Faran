# Filters

Filters smooth the optimal control sequence output by the planner, reducing jitter from noisy sampling.

## Available Filters

| Filter | Description |
|--------|-------------|
| [Savitzky-Golay](savgol.md) | Polynomial-fitting smoothing filter |
