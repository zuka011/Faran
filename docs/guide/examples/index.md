| [Path Following with Boundaries](path-following-with-boundaries.md)           | Fixed-width corridor, boundary cost               |
| [Obstacle Avoidance](obstacle-avoidance.md)                                   | Static obstacles, circle distance, collision cost |
| [Obstacle Avoidance with Uncertainty](obstacle-avoidance-with-uncertainty.md) | Moving obstacles, covariance, risk metric         |
