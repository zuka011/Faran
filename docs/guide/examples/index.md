# Examples

Complete [MPCC](../concepts/mpcc.md) planning scenarios, each building on the previous one. Click the **Result** tab to see the interactive visualization, or expand **Full code** for the entire script.

Each example can also be run as a Jupyter notebook via the Binder badge.

| Example | Features |
|---------|----------|
| [Basic Path Following](basic-path-following.md) | Bicycle model, S-curve, core planning loop |
| [Path Following with Boundaries](path-following-with-boundaries.md) | Fixed-width corridor, boundary cost |
| [Obstacle Avoidance](obstacle-avoidance.md) | Static obstacles, circle distance, collision cost |
| [Obstacle Avoidance with Uncertainty](obstacle-avoidance-with-uncertainty.md) | Moving obstacles, covariance, risk metric |
